🔍 Phân tích Kết quả

❓ Element sẽ hiển thị màu gì?

✅ Đỏ Dodger Blue (#1e90ff) từ Rule 9

Lý do:

  • Rule 9 có ID selector → Specificity (1, 0, 0)
  • ID selector có độ ưu tiên cao nhất trong 10 rules này
  • So sánh: (1,0,0) > (0,2,0) > (0,1,2) > (0,1,1) > (0,1,0) > (0,0,1)
  • Mặc dù Rule 9 được định nghĩa sớm, nhưng specificity cao → nó "thắng"

❓ Nếu thay đổi thứ tự CSS trong file?

❌ Kết quả KHÔNG đổi → Vẫn là Dodger Blue

Giải thích:

  • Specificity > Thứ tự: Độ ưu tiên (specificity) quyết định kết quả, không phải vị trí trong file
  • Ngay cả nếu đặt Rule 9 cuối, nó vẫn thắng vì (1,0,0) > tất cả các rules khác
  • Thứ tự chỉ quan trọng khi specificity BẰNG NHAU → khi đó rule sau cùng thắng
  • Ví dụ: Nếu cả 2 rules đều là (0,1,0), rule được định nghĩa sau sẽ áp dụng

⚠️ Trường hợp Đặc biệt: !important

Nếu thêm !important vào Rule 1:

span { color: black !important; }

Kết quả: Element sẽ thay đổi thành BLACK

Lý do: !important có độ ưu tiên cao hơn bất kỳ selector nào (ngoại trừ !important khác)

💡 Mẹo ghi nhớ Specificity

Công thức Specificity

(a, b, c)

  • a = ID (#)
  • b = Class (.) + Pseudo-class (:)
  • c = Element

Quy tắc So sánh

(1,0,0) > (0,∞,∞)

  • 1 ID > 1000 classes
  • 1 ID > 1000 elements
  • 100 classes > 10000 elements

Inline Style

(1,0,0,0) Inline > All selectors

<span style="color: red;">

!important

Cao nhất!

Tránh dùng trừ khi thực sự cần (bad practice)

🔧 Kiểm tra trong DevTools

  1. Mở DevTools: F12 hoặc Ctrl+Shift+I
  2. Inspect "Hello World" element
  3. Tìm tab Styles / Computed
  4. Xem tất cả CSS rules áp dụng cho element
  5. Các rules bị "gạch đi" = bị override bởi rule khác (specificity cao hơn)
  6. Rule không bị gạch = rule "thắng" → được áp dụng cuối cùng
