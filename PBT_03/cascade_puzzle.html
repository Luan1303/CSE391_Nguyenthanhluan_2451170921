🧩 Cascade & Inheritance Puzzle - Phần C2

Phần 1: Đặt Vấn Đề

CSS Rules:

body { font-size: 16px; color: #333; }
.container { font-size: 14px; }
.card { color: blue; }
.card .title { font-size: 20px; }
.card p { color: inherit; }
#featured .title { color: red; }
.highlight { color: green !important; }

HTML Structure:

<div class="container">
<div class="card featured" id="featured">
<h2 class="title">Sản phẩm A</h2>
<p>Mô tả sản phẩm</p>
</div>
<div class="card">
<h2 class="title">Sản phẩm B</h2>
<p class="highlight">Mô tả sản phẩm B</p>
</div>
</div>

Phần 2: Dự Đoán Kết Quả (Không Chạy Code)

Element Property Giá trị Giải thích
1. "Sản phẩm A" (h2) font-size 20px Từ .card .title { font-size: 20px; }
color red Từ #featured .title { color: red; } (ID specificity cao hơn class)
2. "Mô tả sản phẩm" (p) color blue inherit từ parent .card { color: blue; }

Phần 3: Giải Thích Chi Tiết Cascade & Inheritance

1️⃣ "Sản phẩm A" - font-size: 20px, color: red

🔍 Font-size = 20px:

body (16px) ↓ (inherited) .container (14px) ❌ doesn't apply to h2 directly ↓ .card (inherited from parent) - NO font-size rule ↓ .card .title (20px) ✅ MATCH! Specificity: (0,2,1) ↓ RESULT: 20px
💡 Giải thích:

Element là h2.title inside .card:

  • .container { font-size: 14px; } - KHÔNG áp dụng cho h2 (h2 nằm inside .card, không direct child của .container)
  • .card .title { font-size: 20px; } - ✅ MATCH! Descendant selector
  • Specificity: (0, 2, 1) - cao nhất → kết quả: 20px

🔍 Color = red:

body (color: #333) ↓ .card (color: blue) - Cascade trên parent ↓ #featured .title (color: red) ✅ MATCH! Specificity: (1,1,1) ↓ SPECIFICITY COMPARISON: #featured .title: (1,1,1) .card: (0,1,0) ID selector thắng! ✅ ↓ RESULT: red
💡 Giải thích:

Element là h2.title với id="featured" (parent):

  • .card { color: blue; } - Áp dụng (parent)
  • #featured .title { color: red; } - ✅ Specificity (1,1,1)
  • So sánh: (1,1,1) > (0,1,0) → ID selector thắng
  • Kết quả: red

2️⃣ "Mô tả sản phẩm" - color: blue (inherited)

.card { color: blue; } (parent .card) ↓ .card p { color: inherit; } ✅ MATCH ↓ inherit = lấy từ parent ↓ Parent color = blue (từ .card rule) ↓ RESULT: blue
💡 Giải thích Inheritance:
  • .card { color: blue; } - Áp dụng cho .card element
  • .card p { color: inherit; } - Selector match, nhưng giá trị là inherit
  • inherit = "lấy giá trị từ parent element"
  • Parent (.card) có color: blue → child (p) inherit blue
  • Kết quả: blue
ℹ️ Lưu ý Inheritance: Một số properties tự động inherited (color, font-size, font-family, line-height). Nhưng khi dùng inherit keyword, nó rõ ràng yêu cầu inheritance.

3️⃣ "Sản phẩm B" - font-size: 20px, color: blue

🔍 Font-size = 20px:

.card .title { font-size: 20px; } ✅ MATCH ↓ Specificity: (0,2,1) ↓ RESULT: 20px
💡 Giải thích:

Element cũng là h2.title inside .card (nhưng không có #featured):

  • .card .title { font-size: 20px; } - Match → 20px
  • Không có rule nào khác đặc biệt hơn

🔍 Color = blue:

body (color: #333) ↓ .card (color: blue) ✅ MATCH! Specificity: (0,1,0) ↓ #featured .title rule KHÔNG áp dụng (element không có #featured parent) ↓ RESULT: blue
💡 Giải thích:
  • Element nằm trong .card (bình thường, không #featured)
  • .card { color: blue; } - Parent có rule này
  • h2.title KHÔNG match #featured .title (không có #featured parent)
  • Kết quả: blue (từ .card)

4️⃣ "Mô tả sản phẩm B" - color: green (!important)

.card { color: blue; } (from parent) ↓ .card p { color: inherit; } (would inherit blue) ↓ .highlight { color: green !important; } ✅ MATCH ↓ !important beats everything! Specificity doesn't matter with !important ↓ RESULT: green
💡 Giải thích !important:
  • .highlight { color: green !important; } - Element match (class="highlight")
  • !important có ưu tiên cao nhất (ngoại trừ !important khác)
  • Mặc dù color: inherit sẽ inherit blue từ parent
  • !important thắng mọi cascade rule
  • Kết quả: green
⚠️ Lưu ý !important: Tránh lạm dụng !important

Phần 5: Những Khái Niệm Chính

🔀 Cascade

Thứ tự ưu tiên CSS rules:

  1. !important (cao nhất)
  2. Inline style
  3. ID selector
  4. Class/Attribute
  5. Element (thấp nhất)

👨‍👧 Inheritance

Một số properties tự động inherited từ parent:

  • ✅ color, font-size, font-family
  • ✅ line-height, text-align
  • ❌ width, padding, margin, border

🎯 Specificity Rule

Khi cùng element match nhiều rules:

(IDs, Classes, Elements)
(1,0,0) > (0,2,0) > (0,1,2) > (0,0,1)

1 ID > 1000 classes > 10000 elements
