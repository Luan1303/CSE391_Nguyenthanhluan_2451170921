🔧 Debug CSS Layout - Phần C1

Bước 1: Phân Tích Vấn Đề

❌ Vấn đề: Container rộng 960px, nhưng sidebar + content bị đẩy xuống dòng mới

Tính chiều rộng thực tế (content-box):

Element Width Padding Border Thực tế
Sidebar 300px 20px × 2 = 40px 1px × 2 = 2px 342px
Content 660px 30px × 2 = 60px 1px × 2 = 2px 722px
Tổng: 1064px ❌ > 960px
💡 Giải thích:

Khi dùng box-sizing: content-box (mặc định):

  • Sidebar: 300 + 40 (padding) + 2 (border) = 342px
  • Content: 660 + 60 (padding) + 2 (border) = 722px
  • Tổng: 342 + 722 = 1064px > 960px ❌
  • Kết quả: Content bị float left nhưng không đủ chỗ → wrap xuống dòng

Phần 3: Cách Sửa #1 - Dùng border-box

✅ Giải pháp: Thêm box-sizing: border-box
CSS Code: 
.sidebar {
    width: 300px;
    padding: 20px;
    border: 1px solid #ccc;
    float: left;
    box-sizing: border-box;  /* ADD THIS */
}

.content {
    width: 660px;
    padding: 30px;
    border: 1px solid #ccc;
    float: left;
    box-sizing: border-box;  /* ADD THIS */
}
Element Width (Set) Bao gồm Thực tế
Sidebar 300px content + padding + border 300px
Content 660px content + padding + border 660px
Tổng: 960px ✅ = 960px
✅ Kết quả: Với box-sizing: border-box, width đã bao gồm padding + border → tổng = 960px chính xác!

✅ Sidebar + Content vừa hoàn hảo cạnh nhau

Container: 960px (border-solid xanh)
Sidebar (border-box)

Width: 300px
Box-sizing: border-box
Thực tế: 300px ✅

Content (border-box)

Width: 660px
Box-sizing: border-box
Thực tế: 660px ✅

✅ Hoàn hảo! Sidebar + Content xếp nằm ngang = 960px

Phần 4: Cách Sửa #2 - Không dùng border-box (Giảm width)

✅ Giải pháp: Giảm width để tính vào padding + border
CSS Code: 
.sidebar {
    width: 260px;  /* Reduced from 300px */
    padding: 20px;
    border: 1px solid #ccc;
    float: left;
    /* NO box-sizing needed */
}

.content {
    width: 600px;  /* Reduced from 660px */
    padding: 30px;
    border: 1px solid #ccc;
    float: left;
    /* NO box-sizing needed */
}
Element Width (Reduced) Padding Border Thực tế
Sidebar 260px 20×2=40px 1×2=2px 302px
Content 600px 30×2=60px 1×2=2px 662px
Tổng: 964px ≈ 960px
✅ Cách tính:
  • Sidebar: 260 + 40 + 2 = 302px
  • Content: 600 + 60 + 2 = 662px
  • Tổng: 302 + 662 = 964px ≈ 960px (có thể điều chỉnh thêm)

✅ Sidebar + Content vừa cạnh nhau (không dùng border-box)

Container: 960px (border-solid xanh)
Sidebar (width giảm)

Width: 260px
Padding: 20px
Thực tế: 302px ✅

Content (width giảm)

Width: 600px
Padding: 30px
Thực tế: 662px ✅

✅ Hoạt động! Nhưng cách tính phức tạp hơn

Phần 5: So Sánh 2 Cách Sửa

Tiêu chí Cách #1 (border-box) Cách #2 (giảm width)
Dễ hiểu ✅ Rất dễ (1 dòng) ❌ Phức tạp (phải tính)
Bảo trì ✅ Dễ (không cần tính lại) ❌ Khó (đổi padding phải tính lại width)
Đề xuất ✅✅✅ BEST PRACTICE ⚠️ Tránh nếu có thể
Thực tế ✅ Được dùng rộng rãi ❌ Legacy code (old IE)
🎯 Kết luận Best Practice:

Luôn dùng * { box-sizing: border-box; } ở đầu project CSS:

* {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}

Lợi ích:

  • ✅ Width = tất cả (content + padding + border)
  • ✅ Dễ tính, dễ dự đoán
  • ✅ Layout không bị vỡ vì padding
  • ✅ Giảm BUG, dễ maintain
