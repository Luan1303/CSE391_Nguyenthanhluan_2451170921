Phần 1: Content-Box vs Border-Box (Demonstration)

Cùng width=300px, padding=20px, border=5px - nhưng box-sizing khác nhau

Hộp 1: content-box

Width: 300px (content ONLY)

padding: 20px | border: 5px

Tổng hiển thị: 300 + 40 + 10 = 350px

Hộp 2: border-box

Width: 300px (content + padding + border)

padding: 20px | border: 5px

Content chính xác: 300 - 40 - 10 = 250px

💡 Giải thích:

  • content-box: width = chiều rộng nội dung, padding + border tính thêm
  • border-box: width = tổng nội dung + padding + border
  • Mở DevTools (F12) → Inspect Element → Tab Computed để xem box model diagram

📐 Tính toán chi tiết (không dùng border-box):

Cột Width Padding Border Chiều rộng thực
Trái 250px 15px × 2 1px × 2 250 + 30 + 2 = 282px
Giữa 500px 20px × 2 1px × 2 500 + 40 + 2 = 542px
Phải 250px 15px × 2 1px × 2 250 + 30 + 2 = 282px
TỔNG: 282 + 542 + 282 = 1106px ❌

⚠️ Vượt 1000px lên 106px → cột phải bị wrap!

📐 Tính toán chi tiết (dùng border-box):

Cột Width Bao gồm Chiều rộng thực
Trái 250px content + padding + border 250px
Giữa 500px content + padding + border 500px
Phải 250px content + padding + border 250px
TỔNG: 250 + 500 + 250 = 1000px ✅

✅ Chính xác 1000px → 3 cột xếp hoàn hảo!

🔧 Cách sử dụng DevTools để kiểm tra Box Model

  1. Mở DevTools: Nhấn F12 hoặc Ctrl+Shift+I
  2. Chọn tab Elements / Inspector
  3. Inspect element: Nhấp vào hộp muốn kiểm tra
  4. Tìm tab Computed Styles / Box Model
  5. Xem diagram màu sắc:
    • 🟠 Orange = Margin
    • 🟡 Yellow = Border
    • 🟢 Green = Padding
    • 🔵 Blue = Content

Số liệu từ DevTools cho phép xác minh lý thuyết!
